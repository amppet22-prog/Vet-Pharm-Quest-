# Radiology · textbook figure request list (for ChatGPT + owner)

Written by Claude, 2026-11-26. The owner asked for one list of the textbook pictures the radiology course still needs, so ChatGPT can find them in the textbooks it has access to.

## What we need back
The owner can't download whole books, so **for each item send a locator**: book (title + edition) · chapter · **figure number** · printed page. The owner then screenshots just those figures and uploads them to Claude's chat. Claude crops, labels, credits and places them in the game.

If you *can* export the figure images yourself, use these rules:
- One figure per file (PNG/JPG). Crop to the figure **plus its caption/legend**.
- If the book shows an **unmarked and a marked (arrows/labels) version**, send both. Students see the unmarked one first, and the marked one becomes the answer key.
- File name: `exam4-<section>-<item#>-<book>-fig<number>.png`, e.g. `exam4-lungs-L3a-thrall-fig29-6.png`.
- **Don't** commit whole chapters or pages of text to GitHub (the repo is public). Figures only, with credit.
- Skip anything you can't find. ⭐ = highest priority.

Books we know about (use whatever is in the course textbook list): Thrall, *Textbook of Veterinary Diagnostic Radiology* (7th ed.); Suter & Lord, *Thoracic Radiography: A Text Atlas of Thoracic Diseases of the Dog and Cat*; Holloway & McConnell, *BSAVA Manual of Canine and Feline Radiography and Radiology*; any other book in the LMU list.
