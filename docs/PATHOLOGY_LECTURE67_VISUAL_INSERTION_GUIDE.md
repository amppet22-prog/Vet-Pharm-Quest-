## Publishing and image rights

- Do not commit lecture-deck screenshots or textbook plates to the public GitHub repository unless the rightsholder has given appropriate permission. Existing private access for studying does **not** establish redistribution rights.
- For freely licensed images, verify the specific file page, creator, license, required attribution and share-alike terms before downloading. Prefer veterinary species over human exemplars; label human specimens as human when used.
- Author original mechanism schematics for CSF flow, BBB, pathogen routes and edema; label them as original teaching diagrams, not professor-supplied images.
- All learning cards should include **What you see → Why it happens → Clinical implication → Don't confuse with → Image attribution** and a click-to-enlarge view.

## Textbook enhancements (explicitly supplemental)

1. **CNS versus PNS Wallerian degeneration:** Chapter 14 explains why CNS axons recover poorly compared with PNS axons: slower debris clearance, restricted oligodendrocyte remyelination, and lack of Schwann-cell/endoneurial guidance found in peripheral nerves. Put this into the Wallerian degeneration “WHY?” panel but mark as **Textbook enrichment**.
2. **Edema classification:** The lecture emphasizes cytotoxic (intracellular, intact BBB) and vasogenic (extracellular, BBB disrupted). The textbook additionally describes **hydrostatic/interstitial** edema from increased intraventricular pressure and **hypo-osmotic** edema from osmotic imbalance. Keep these as expandable enrichment, not automatically assigned professor exam priority.
3. **Central chromatolysis:** Textbook Fig. 14.19 illustrates an eccentric nucleus with redistribution of Nissl substance; this is **not** the same image diagnosis as the small shrunken red neurons of neuronal necrosis. Useful in a comparison panel, not as a substitute for Lecture 67's neuron-necrosis photograph.

## Priority for the first visual pass

**Must add first:** normal dog brain, gray/white matter, neuronal necrosis, Wallerian degeneration, cerebral edema gross, cytotoxic-vs-vasogenic edema, primary-vs-secondary demyelination.  
**Next:** astrocytes, microglia, ependyma, meninges, CSF circulation, BBB, cerebral infarcts and four pathogen routes.

## Proposed per-image UI

- Caption directly under image, readable without opening extra panels.
- Expand image with a click; avoid cropping pathologic regions.
- Toggle **Show labels / Hide labels** for self-testing.
- **Why?** opens mechanism. **Don't confuse with** compares the nearest mimic.
- Record source page or URL, photographer, license, species, stain, and original orientation.
