# Pathology Exam 2 public lecture photographs

These images were selected from instructor-annotated lectures 26–30, with permission for public display confirmed by the project owner.

## Install the original images
Extract `pathology_exam2_public_photo_assets.zip` and upload the 16 `.jpg` files from its `assets/pathology/exam2/` folder **directly into this GitHub folder**. Keep filenames unchanged. Do not upload the ZIP as a single asset: GitHub Pages needs the extracted files.

The game reads `pathology-exam2-photo-index.js` and recognizes a photo only when its exact JPEG path exists. It then displays a caption, slide citation and recognition clue on the mapped atlas card. A published owner gallery takes priority.

`manifest.json` documents source lecture, slide, card ID and diagnostic clue for each expected photo.

## Verification
Once uploaded, open `https://amppet22-prog.github.io/Vet-Pharm-Quest-/assets/pathology/exam2/lecture28-p21-mast-cell-low-grade.jpg`: it should return the annotated photograph, not a 404. Then open the corresponding Lecture 28 Mast Cell Tumor atlas card.

Do not confuse old placeholder images in `assets/pathology/` with these extracted source photographs.
